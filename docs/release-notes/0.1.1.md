This release adds a second way to install Who's Working: one command in Terminal. The app itself is the same as 0.1.0.

**Requirements:** macOS 15 or later on an Apple silicon Mac.

**Install with a command (new)**

```bash
curl --proto '=https' --tlsv1.2 -fsSL -o whoisworking-install.sh https://github.com/Bakhtiyor7/whoisworking-releases/releases/download/v0.1.1/install.sh && sh whoisworking-install.sh
```

The script downloads `WhoIsWorking-0.1.1.dmg` from this release, checks it against the SHA-256 written inside the script, copies the app to Applications and opens it. It never uses `sudo` and never asks for a password. If Who's Working is already installed, it replaces that copy, and your installed hooks keep working.

Things to know before you run it:

- It is saved as `whoisworking-install.sh` in the folder you are in, so you can read it first, or afterwards.
- The app is not notarized by Apple. A disk image downloaded in a browser goes through macOS's first-launch check; an app installed this way does not. The checksum catches a damaged download. It does not prove who made the app.
- If you rarely use Terminal, macOS may show a "Paste blocked" alert when you paste the command. Choose **Paste Anyway** if you trust this page.
- On a standard (non-admin) account the script cannot write to Applications and will say so. Use the disk image instead.

This route is new. If macOS shows a dialog we did not describe, please open an [issue](https://github.com/Bakhtiyor7/whoisworking-releases/issues) and tell us what it said.

**Or install from the disk image**

1. Download `WhoIsWorking-0.1.1.dmg` below and open it.
2. Drag **Who's Working** into **Applications**, then eject the disk image.
3. Open Who's Working from Applications. This build is not notarized by Apple, so macOS blocks the first launch:
   - Click **Done** in the dialog.
   - Open **System Settings › Privacy & Security** and scroll down.
   - Click **Open Anyway** next to "Who's Working", then confirm with your password.

   Or, in Terminal: `xattr -dr com.apple.quarantine "/Applications/WhoIsWorking.app"`
4. Open Who's Working again. Hover the notch to see your sessions.

**Updating from 0.1.0**

Run the command above, or quit Who's Working and replace the app in Applications with the one from the disk image. Either way, the hooks you installed keep working.

Status only: Who's Working never approves or denies anything for an agent.
