# Code of conduct

Who's Working follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the issues, pull requests, discussions and every other place the project has, and whenever someone represents the project elsewhere.

In short: be kind and patient, assume good faith, and accept that people disagree. Harassment, insults, personal attacks, sexual language or imagery, and publishing someone's private information are not accepted.

## Reporting

If someone's behaviour worries you, tell the maintainer privately through the repository's private report form, the one [SECURITY.md](SECURITY.md) uses for security problems. Start the title with "Conduct:". Only you and the maintainer can see it, and your report is kept confidential.

https://github.com/Bakhtiyor7/whoisworking/security/advisories/new

The maintainer decides what to do, following the Contributor Covenant's enforcement guidelines: from a private word, through a warning or a temporary ban, to a permanent ban from the project.
